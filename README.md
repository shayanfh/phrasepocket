# Phrase Pocket

یک وب‌اپ استاتیک و بدون بک‌اند برای ذخیره و مرور عبارت‌های روزمره انگلیسی.

## امکانات

- ثبت سریع عبارت، معنی، جمله شنیده‌شده و جمله شخصی
- صندوق ورودی برای ثبت فوری و تکمیل در زمان دیگر
- جست‌وجو و فیلتر
- مرور فلش‌کارت با فاصله‌گذاری ساده
- ذخیره اطلاعات داخل مرورگر دستگاه
- خروجی و بازیابی فایل JSON
- نصب روی Home Screen آیفون
- کار آفلاین پس از اولین باز شدن

## اجرای محلی

Service Worker از مسیر `file://` اجرا نمی‌شود. برای تست کامل، داخل پوشه پروژه یکی از این دستورها را اجرا کن:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کن.

## انتشار رایگان با GitHub Pages

1. یک repository جدید در GitHub بساز.
2. همه فایل‌های داخل این پوشه را در ریشه repository قرار بده.
3. در GitHub به `Settings → Pages` برو.
4. در بخش Build and deployment گزینه `Deploy from a branch` را انتخاب کن.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذار و Save را بزن.
6. آدرس ساخته‌شده را در Safari آیفون باز کن و `Share → Add to Home Screen` را انتخاب کن.

## نکته مهم درباره اطلاعات

اطلاعات فقط روی همان مرورگر و دستگاه ذخیره می‌شود. پاک کردن داده‌های Safari یا حذف کامل داده‌های سایت می‌تواند اطلاعات را حذف کند؛ بنابراین مرتب از بخش «بکاپ» خروجی بگیر.
